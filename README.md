# Piyush Santosh Raut - Developer Portfolio

A modern developer portfolio website built with a dark purple/blue glassmorphism aesthetic, glowing neon effects, hover animations, an interactive particle mesh background, and a developer CLI console.

## 🚀 Key Features
- **Visual Aesthetic**: Dark Obsidian (`#090714`), Deep Violet (`#0d0b1e`), Electric Purple (`#a855f7`), and Glowing Cyan (`#00f2fe`).
- **Glassmorphism**: High-performance backdrop blur (`backdrop-filter: blur(16px)`), frosted glass cards, and ambient background aura glowing orbs.
- **Interactive CLI Console**: Virtual bash terminal executing commands (`mountreach`, `skills`, `projects`, `about`, `contact`, `whoami`, `matrix`, `clear`).
- **Canvas Particle Mesh**: Interactive particle network reacting to cursor movement.
- **3D Card Tilt Physics**: Sheen sweep animations and 3D card tilt effects.
- **Responsive Layout**: Designed for Desktop, Tablet, and Mobile devices.

## 🛠️ Tech Stack
- **Frontend**: HTML5, Modern CSS3 (Variables, Flexbox/Grid, Animations), JavaScript (ES6+)
- **Graphics & Icons**: WebGL/Canvas API, FontAwesome 6, Google Fonts (Syne, Inter, JetBrains Mono)
